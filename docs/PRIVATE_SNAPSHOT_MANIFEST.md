# Private Snapshot Manifest

This repository was assembled as a clean, selected snapshot rather than initialized inside the full working directory.

Included:

- complete `paper/` tree;
- `benchmarks/delegation_bench_v1/`;
- `benchmarks/delegation_bench_crossmodel_v13/`;
- complete `experiments/`, `models/`, `runners/`, and `tests/` trees;
- `results/delegation_bench_v1/`;
- `results/delegation_bench_crossmodel_v13/`;
- `results/delegation_transition_pilot/`.

Excluded:

- original Git metadata and history;
- environment files, secrets, caches, and temporary files;
- unrelated experimental result and benchmark lines from the larger workspace;
- host-specific IDE state.

The private snapshot intentionally retains raw trajectories, intermediate QC artifacts, infrastructure failures, and archived negative/inconclusive lines to preserve the research process.
